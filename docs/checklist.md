# Checklist de revisión de requisitos  

| # | Pregunta | R-01 | R-02 | R-03 | R-04 |
|---|----------|------|------|------|------|
| 1 | ¿El requisito es medible o tiene un criterio de aceptación claro?| No | No | Parcial | No |
| 2 | ¿Usa palabras subjetivas (rápido, importante, especial, correcto)? | Sí | Sí | No | Sí |  
| 3 | ¿Todos los términos clave están definidos? | No | No | No | No |
| 4 | ¿Se puede diseñar una prueba a partir de este requisito? | No | No | Parcial | No |
| 5 | ¿Se especifican valores concretos (números, umbrales, porcentajes)? | No | No | No | No |
| 6 | ¿Están definidas las excepciones y casos límite? | No | No | Parcial | No |
| 7 | ¿Es coherente con los demás requisitos? | Sí | Sí | Sí | Sí |
| 8 | ¿Es atómico (dice una sola cosa)? | Sí | Sí | No | Sí | 
| 9 | ¿Tiene un responsable de negocio que pueda confirmarlo? | No | No | No | No |
